# Exemples `.eml` synthétiques

Ces fichiers sont entièrement fictifs et conçus pour les exercices locaux. Les domaines `.invalid` sont réservés à des usages non réels. Aucun lien ne doit être visité.

- `01-urgence-authentification.eml` : urgence, adresse de réponse différente et résultats d'authentification contradictoires.
- `02-lien-destination-differente.eml` : texte affiché d'un lien différent de sa destination.
- `03-facture-fictive.eml` : message de référence sans demande pressante.

- `04-piece-jointe-synthetique.eml` : pièce jointe texte inoffensive pour apprendre à relever ses métadonnées.

Les lignes `Authentication-Results` sont des valeurs placées dans le message pour l'exercice ; elles ne constituent pas une vérification indépendante de SPF, DKIM ou DMARC.
