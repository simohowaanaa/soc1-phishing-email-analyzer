# Échantillons réels publiés — avertissement

Ces deux messages sont des échantillons réels issus du dépôt public [rf-peixoto/phishing_pot](https://github.com/rf-peixoto/phishing_pot), utilisé pour la recherche et la détection de phishing. Les copies de ce dépôt sont adaptées : les parties nominatives des adresses sont remplacées par `redacted` et les URL sont défangées (`hxxps`, `[.]`). Ce ne sont donc pas des preuves forensiques intactes.

> **Avertissement : contenu hostile.** N’ouvrez pas ces fichiers dans un client de messagerie ou un navigateur. Ne visitez aucun lien, ne dé-fangez pas les URL et n’ouvrez ni n’exécutez de pièce jointe. Analysez les fichiers comme du texte brut. Les résultats SPF/DKIM/DMARC sont des valeurs observées dans le message, pas une validation indépendante.

## Fichiers

- `sample-1-public-phishing.eml` — faux message Bradesco Livelo ; objet sur l’expiration de points.
- `sample-10-faux-avertissement-microsoft.eml` — faux avertissement de connexion Microsoft.

Les originaux téléchargés sont conservés hors du dépôt dans `CV + Projet\Exemples e-mail publics`. Aucun fichier de pièce jointe n’est inclus dans les copies publiées.
