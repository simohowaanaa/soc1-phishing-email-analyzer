# Parcours du projet

1. Créer le squelette et définir les règles de sécurité.
2. Lire les métadonnées et en-têtes d’un fichier `.eml`.
3. Analyser prudemment le texte, les liens et les pièces jointes.
4. Produire un rapport JSON et Markdown compréhensible par un analyste N1.
5. Valider sur des exemples fictifs, documenter et préparer la publication.

Chaque étape séparera les faits observés, les hypothèses et les limites. Les liens ne seront pas visités et les pièces jointes ne seront pas ouvertes.
